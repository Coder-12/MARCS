🚀 What is MARCS?

MARCS is a production-grade AI-driven code review system built with crash-safe patch application, journaling, artifact generation, and full webhook automation.

✨ Features

Crash-Safe Apply

Atomic patch application with backups and recovery.

HTML Reports

Human-friendly static reports generated for every event.

Webhook Automation

Plug-and-play with GitHub webhook events.

Safety Engine

Detects dangerous patterns such as eval, os.system, etc.

🔧 CLI Usage

./scripts/demo_orchestrator.py \
  --event-id demo \
  --repo-root demo-repo \
  --review-json review.json \
  --yes

📦 Artifacts Generated

  • review.json
  • apply_result.json
  • report.html
  • journals/*.jsonl
  • backups/*.bak
